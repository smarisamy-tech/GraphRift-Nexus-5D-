# GraphRift 5D — Full-Stack 3D Canonical Trend Intelligence Dashboard

A full-stack 3D WebGL knowledge graph and trend clustering engine with a **Node.js / Express** persistent backend, **Google Sheets bidirectional sync**, **RSS XML ingestion**, and **Excel `.xls` workbook export**.

## Repository Structure

```text
graphrift-5d-dashboard/
├── index.html        # Three.js / WebGL 5D Frontend + Zorg-5D Autonomous Scout
├── server.js         # Node.js / Express REST API, Sheet Sync Proxy & DB Persistence
├── package.json      # Dependencies & start script
└── README.md         # GitHub setup & cloud deployment instructions
```

## Quick Start (Local & GitHub)

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run Full-Stack Server**
   ```bash
   npm start
   ```
   Open `http://localhost:3000` in your browser.
